西雅图那台的 CPU 是 Intel E5-2680 v2，主频 2.80GHz，10 核 20 线程的服务器 CPU 切出来的 1 核。测评作者自己的评价是“跑分一般，毕竟是 1 核 1G 入门最低配”，这个判断比任何跑分数字都实在。

两台的磁盘差距值得说明一下：757.3MB/s 和 479.7MB/s 差了 58%，但这是两台不同机器、相隔半年的结果，不能当成“西雅图比芝加哥快”。同一机房不同母机之间的波动也有这个量级，把它理解成 480–760MB/s 的参考区间更合适。

低配套餐存在超售，这是公开测评里明确提到的：高负载或突发性能场景下会和邻居抢资源。要跑数据库、要跑高并发，直接上 4GB 以上，别拿 1GB 硬扛。这条不是劝你多花钱，1GB 的 CPU 份额在数据库负载下确实撑不住。

### 圣何塞：三网都能用，电信联通最舒服

圣何塞是唯一一个三网下载都能稳定跑过 400Mbps 的机房，上传也在 300Mbps 以上。电信 145–160ms、联通 165–185ms、移动 195–225ms，移动稍高但不像 DC-02 那样两极分化。测评里对它的描述是“不挑本地网络”，这在美西普通线路机房里不算常见。

晚高峰丢包基本为 0，偶尔有 1–2% 的波动。如果你只买一台、又不想为了运营商纠结，圣何塞是默认答案。

### 洛杉矶 DC-02：两份数据不能说成同一个结论

DC-02 的数据是所有机房里最分裂的。一份测评的分运营商表格给出的是：电信约 261ms 配 52Mbps 下载、联通约 259ms 配 74Mbps、移动约 164ms 配 246Mbps，结论是“几乎专门给移动优化，电信联通慎选”。另一份测评则称它是“国内速度最快的一个”，235 个国内节点平均延迟约 197ms，最快节点 135.7ms（上海电信 CN2），本地下载实测约 11MB/s（约 88Mbps），并提到最慢的杭州联通节点 1075ms 属于异常值。

两边差这么多，原因是测试时间、节点集和单线程/多线程口径都不一样：197ms 是 235 个节点的平均值，容易被大量低延迟节点拉低；261ms 是分运营商统计的代表值。写稿时把它们并列，比挑一个当定论更接近事实。可以确定的共同点是：移动在 DC-02 上表现明显好于电信联通，电信晚高峰丢包可能冲到 20% 以上。

### 达拉斯：三网不偏科

国内上传约 300Mbps、下载约 400Mbps，欧美方向上传能到 600Mbps，晚高峰比 DC-02 稳。适合访客来源不确定的站点。延迟不是最低，但没有哪个运营商被明显牺牲。

### 西雅图：能买，但别拿它做面向大陆的站

2022 年那台 $12.99/年 的机器，晚 8 点上行一般、下行尚可，SFTP 传 100MB 文件 8.9MiB/s，本地下载 9.7MB/s。超级 ping 看着“基本一片绿”，但部分地区丢包较多。测评的结论是对面向大陆用户的网站要慎重，做英文站、外贸站随便用。

### 芝加哥：延迟最高的一档

本地 ping 260 多 ms，多地超级 ping 电信均值 233.8ms、联通 281ms、移动 300ms，四川电信晚高峰丢包偏高，奈飞也解不了。它适合海外业务、挂程序、学习折腾，不适合国内访问为主的场景。

## 回程路由和晚高峰：163 骨干，不是 CN2

RackNerd 大部分机房走普通 163 骨干，没有 CN2 GT 或 GIA 优化。圣何塞的电信是 163 接 NTT，联通移动走 GTT。芝加哥的联通走 AS4837、电信走 1263 骨干、移动走 CMI，但电信回程要绕阿什本和圣何塞，联通绕圣何塞，移动经洛杉矶走 AS58453；去程电信走日本 NTT，联通和移动还要绕一趟爱尔兰。西雅图那台机器的电信回程也是绕圣何塞再进广州。

这些绕路不会让机器不能用，但会让延迟比理论值高一截，也解释了为什么同是美西机房，晚高峰表现能差出一个档次。

晚高峰（北京时间 20:00–22:00）的分水岭很清楚：圣何塞丢包基本为 0；DC-02 的电信可能到 20% 以上，移动联通相对稳；其他机房普遍比白天高 3–5 个百分点。电信用户如果已经在 DC-02 上，可以开 BBR 缓解，做法是往 `/etc/sysctl.conf` 里加 `net.ipv4.tcp_congestion_control=bbr` 再执行 `sysctl -p`。物理路由改不了，根治办法是换机房，而机房不能迁移，只能重新下单。

拿到机器后按这个顺序跑：

1. `ping` 测裸延迟，先看数量级对不对得上表格。
2. `speedtest-cli` 可以跑，但它默认选最近的节点，国内方向的参考价值有限，别把它当结论。
3. `wget` 拉一个 1GB 的测试文件，看真实下载速度稳不稳。
4. `mtr` 或 BestTrace 看三网回程，确认有没有绕路。
5. 北京时间 20:00–22:00 再复测一遍，这一步才区分得出机房好坏。

**1Gbps 指的是端口速率**，不是保底带宽。圣何塞实测 wget 稳定在 10–12MB/s（约 80–100Mbps），晚高峰还会降，这属于正常现象。想跑满端口要多个线程并发或者用 iperf3 对打，单线程测不出来。
